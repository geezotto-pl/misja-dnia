# Misja Dnia

Prototyp kreatora postaci aplikacji „Misja Dnia” (roboczo: Sidequest): codzienne misje rozwojowe dopasowane do profilu gracza.

Aplikacja: https://geezotto-pl.github.io/misja-dnia/

Awatary: styl „Lorelei” (Lisa Wischofsky, CC0 1.0) oraz wcześniej „Notionists” (Zoish, CC0 1.0), przez bibliotekę DiceBear (MIT). Czcionka: Caveat (SIL OFL 1.1).
